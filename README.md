# Sterling Strategy

Quero que você CRIE/REFORMULE o site de uma advocacia com uma estética extremamente moderna, sofisticada e de ALTO PADRÃO.

IMPORTANTE: não quero que você simplesmente faça um site jurídico comum com cores bonitas.

Quero uma experiência visual premium, semelhante ao nível de apresentação de grandes escritórios e marcas de luxo.

O resultado precisa parecer um projeto feito por um estúdio profissional de design e desenvolvimento.

CONCEITO PRINCIPAL

A direção visual deve combinar:

advocacia premium;

luxo discreto;

design editorial;

minimalismo;

arquitetura;

tecnologia;

sofisticação;

autoridade;

confiança.

A sensação deve ser:

"Um escritório de advocacia sério, exclusivo, moderno e altamente profissional."

Não quero uma estética de escritório jurídico tradicional.

Quero algo contemporâneo.

ESTILO VISUAL

Criar um design predominantemente:

minimalista;

elegante;

sofisticado;

clean;

editorial;

com bastante espaço negativo;

grandes títulos;

imagens grandes;

composição assimétrica;

linhas finas;

detalhes discretos;

animações suaves.

Evitar aparência de template.

Evitar excesso de cards.

Evitar excesso de ícones.

Evitar elementos jurídicos clichês.

NÃO utilizar como elemento principal:

balança da justiça;

martelo;

estátua da justiça;

tribunal genérico;

aperto de mãos genérico;

advogado de banco de imagens;

prédios jurídicos clichês.

PALETA

Usar uma paleta extremamente elegante.

Base:

OFF-WHITE / MARFIM
#F5F3EF aproximadamente

GRAFITE
#171717 aproximadamente

PRETO
#0B0B0B aproximadamente

CINZA
para textos secundários.

Detalhes muito discretos em:

CHAMPAGNE / BRONZE

O dourado deve aparecer apenas em pequenos detalhes.

NÃO quero dourado exagerado.

A combinação precisa lembrar:

luxo discreto + arquitetura + alta advocacia.

TIPOGRAFIA

Utilizar duas famílias tipográficas.

TÍTULOS:

Uma serif sofisticada e editorial.

Exemplos:

Cormorant Garamond
DM Serif Display
Playfair Display

CORPO:

Inter
Manrope
Plus Jakarta Sans

Criar contraste forte entre:

TÍTULOS ELEGANTES

e

TEXTOS MODERNOS.

Os títulos podem ser grandes, com bastante espaço entre linhas.

HEADER

Criar um header extremamente refinado.

No desktop:

ESQUERDA:
nome/logotipo da advocacia.

DIREITA:

Início
O Escritório
Atuação
Diferenciais
Conteúdo
Contato

E um botão:

FALAR COM UM ADVOGADO

O header deve ter bastante espaço.

Nada apertado.

Nada com aparência de dashboard.

HEADER DINÂMICO

No início da página:

Header mais transparente/integrado ao Hero.

Ao rolar:

fundo levemente sólido;

blur;

backdrop-filter;

sombra quase imperceptível;

transição suave.

O header deve permanecer elegante.

Criar animação nos links.

Ao passar o mouse:

uma linha fina aparece abaixo do item.

A animação deve ser rápida e sofisticada.

MENU MOBILE

No celular:

utilizar hamburger.

Ao clicar:

abrir um menu fullscreen elegante.

O menu deve aparecer com animação.

Criar:

fundo escuro ou off-white;

links grandes;

animação individual dos links;

botão de contato.

A abertura deve parecer uma experiência premium.

HERO

Essa será a parte mais importante do site.

Quero um HERO cinematográfico.

Não fazer aquele padrão:

"Bem-vindo ao escritório"
texto
botão
imagem.

Quero uma composição editorial.

Criar uma grande headline ocupando boa parte da tela.

Exemplo de direção:

"ESTRATÉGIA
PARA DECISÕES
QUE IMPORTAM."

ou:

"Direito.
Estratégia.
Precisão."

A headline deve ser forte, elegante e grande.

Adicionar uma pequena frase acima:

ADVOCACIA ESTRATÉGICA

Adicionar uma descrição curta.

Adicionar CTA:

Falar com um advogado

E um segundo CTA:

Conhecer o escritório

HERO VISUAL

Utilizar uma imagem profissional de arquitetura, escritório, advogado ou composição sofisticada.

A imagem deve ocupar uma área grande.

Criar tratamento editorial.

Possíveis efeitos:

máscara;

recorte;

overlay;

zoom lento;

parallax;

entrada com clip-path.

Não deixar a imagem parecendo simplesmente uma foto colocada ao lado do texto.

Ela precisa fazer parte da composição.

FUNDO ANIMADO

Quero um fundo animado sofisticado.

NÃO quero partículas aleatórias.

NÃO quero fundo gamer.

Criar uma animação abstrata e extremamente discreta.

Pode utilizar:

gradientes suaves;

luz difusa;

formas geométricas;

linhas finíssimas;

sombras;

ruído/grain;

movimentos lentos;

elementos arquitetônicos abstratos;

círculos ou formas orgânicas extremamente sutis.

O fundo deve se mover lentamente.

A pessoa quase não percebe o movimento.

A sensação deve ser de:

"luxo tecnológico".

ANIMAÇÃO DO HERO

Ao carregar a página:

fundo aparece;

header aparece;

pequeno texto aparece;

headline entra;

descrição aparece;

botões aparecem;

imagem é revelada.

Tudo em sequência.

Utilizar:

opacity
transform
clip-path
scale

com movimentos muito suaves.

SCROLL INDICATOR

Adicionar no Hero um pequeno indicador:

SCROLL

com uma linha vertical animada.

Ao rolar a página, o indicador desaparece.

SEÇÃO DE POSICIONAMENTO

Depois do Hero, criar uma seção extremamente limpa.

Fundo off-white.

Título grande:

"Mais do que orientação jurídica.
Estratégia."

Abaixo, um texto institucional curto.

O texto deve transmitir:

precisão;

estratégia;

conhecimento;

proximidade;

responsabilidade.

Utilizar bastante espaço vazio.

SEÇÃO DE NÚMEROS / AUTORIDADE

Criar uma pequena área de indicadores.

Exemplo:

Atuação estratégica

NÃO inventar números de clientes, processos, anos de experiência ou resultados.

Caso informações reais sejam adicionadas posteriormente, deixar estrutura preparada.

ÁREAS DE ATUAÇÃO

Não quero cards tradicionais.

Criar uma lista editorial sofisticada.

Exemplo:

01 DIREITO TRABALHISTA
────────────────────────

02 DIREITO EMPRESARIAL
────────────────────────

03 DIREITO CIVIL
────────────────────────

────────────────────────

Ao passar o mouse:

pequena descrição aparece;

seta aparece;

área recebe destaque.

Criar uma interação elegante.

No mobile:

cada área vira um bloco expansível.

IMPORTANTE:

Não inventar áreas jurídicas reais.

Usar placeholders caso elas ainda não tenham sido definidas.

SEÇÃO ESCURA

Criar uma grande seção com fundo preto/grafite.

Adicionar uma frase gigante:

"Decisões importantes
exigem precisão."

Criar animação de texto conforme o usuário rola.

Pode utilizar efeito:

text reveal
clip-path
mask
fade

Essa seção precisa ser visualmente marcante.

O ESCRITÓRIO

Criar uma seção editorial.

Uma imagem grande.

Ao lado:

O ESCRITÓRIO

"Uma advocacia construída sobre estratégia, confiança e precisão."

Criar texto institucional.

Não utilizar texto genérico demais.

A apresentação deve parecer a comunicação de uma marca premium.

Adicionar botão:

CONHECER O ESCRITÓRIO

FOTO / IMAGEM

As imagens devem possuir tratamento premium.

Evitar:

fotos clichês;

imagens muito coloridas;

stock photos óbvias.

Preferir:

arquitetura;

interiores sofisticados;

retratos profissionais;

detalhes;

texturas;

ambientes corporativos;

fotografia editorial.

Quando não houver imagens reais disponíveis, utilizar placeholders claramente identificados para substituição posterior.

DIFERENCIAIS

Criar uma seção minimalista.

Não usar quatro cards coloridos.

Criar uma experiência baseada em linhas.

Exemplo:

01 — Estratégia
02 — Precisão
03 — Proximidade
04 — Confiança

Cada item possui uma descrição que aparece ao hover.

Criar microinterações.

Criar uma seção:

"Como trabalhamos"

04

No scroll, a linha vai sendo preenchida.

No mobile, transformar em linha vertical.

BLOCO EDITORIAL

Criar uma grande frase no meio da página.

Exemplo:

"O melhor caminho começa com uma boa estratégia."

Tipografia muito grande.

Poucos elementos.

Muito espaço.

Criar animação conforme o scroll.

ARTIGOS

Título:

"Perspectivas jurídicas"

ler artigo →

Evitar efeitos chamativos.

Criar uma experiência própria para celular.

360px

No mobile:

nenhum overflow horizontal.

Os títulos precisam continuar impactantes sem quebrar palavras de maneira estranha.

O desktop deve aproveitar bastante o espaço horizontal.

Utilizar:

imagens grandes;

títulos gigantes;

bastante espaço negativo;

Testar:

1280px
1440px
1600px

RESPONSIVIDADE

NENHUM elemento pode:

sair da tela;

ficar cortado;

criar scroll horizontal;

sobrepor outro elemento;

quebrar o layout.

PERFORMANCE

As animações precisam ser leves.

Priorizar:

transform
opacity

Otimizar imagens.

Utilizar WebP/AVIF quando possível.

Lazy loading.

Evitar efeitos pesados que prejudiquem FPS.

Implementar prefers-reduced-motion.

CÓDIGO

Se o projeto já possuir uma stack, respeite a estrutura existente.

Se estiver começando:

React
TypeScript
Tailwind CSS
Framer Motion

Criar componentes organizados.

Separar as seções em componentes reutilizáveis.

Manter código limpo.

Não inventar:

OAB;

especializações;

número de processos;

número de clientes;

anos de experiência;

prêmios;

resultados;

depoimentos;

áreas de atuação não confirmadas.

"resultado garantido"
"somos os melhores"
